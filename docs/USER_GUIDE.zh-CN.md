# 使用说明 / 简体中文

## 账号与数据库

首次打开空数据库时自行创建管理员，密码至少 8 个字符。已有数据库使用其中的账号登录。管理员通过界面中的“账号”入口新增、编辑、删除账号；编辑时密码留空表示保留原密码。密码不会在列表中显示。

旧版明文密码在成功登录后升级为带随机盐的 PBKDF2 哈希。升级前保留数据库备份；迁移后不建议用旧版本打开，旧版无法校验新哈希。尚未登录迁移的账号和旧备份仍可能含旧明文密码。账号验证属于本地应用访问控制，数据库文件本身没有加密；拥有该文件系统访问权的人仍可能读取学生数据。请将数据库保存在你信任的本地位置。

## 专业、班级和学生

在左侧组织树中管理专业与班级，选择班级后录入学生。学生以学号识别，学号在同一数据库中不能重复。可以搜索学生、切换排序，并通过界面为学生加减积分、填写原因和查看变更历史。

表格内支持的编辑、档案查看、回收站与撤销以“帮助”窗口和相应按钮为准。删除数据前阅读确认提示。撤销只保留当前运行期间的有限历史，不是长期备份。

## 导入 50 人测试文件

1. 准备独立测试环境，避免把虚构学生混入正式名单。
2. 点击“批量导入新生 (CSV)”，选择 `examples/ScoreManager-50-students.csv`。
3. 空数据库预期导入 50 人、跳过 0 条：2 个专业、5 个班，每班 10 人。
4. 保存并正常退出，再打开确认数据保留。
5. 重复导入同一完整测试文件，预期新增 0 人、跳过 50 条。

导入文件使用 UTF-8，推荐列顺序如下：

```csv
专业,班级,学号,姓名,总分数
测试计算机科学,测试计科1班,TEST0001,测试学生01,-10
```

重复学号、同名班级所属专业冲突、缺少必填信息或无效积分会被跳过。导出 CSV 可在常见表格软件中查看。HTML 报表可由浏览器打开和打印。导入会增加当前数据库中的记录，并非自动替换所有学生。

## 保存与快捷键

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| 保存 | Ctrl+S | Command+S |
| 撤销 | Ctrl+Z | Command+Z |
| 退出 | 关闭主窗口 | 关闭主窗口或 Command+Q |

保存和撤销也可以通过按钮操作。程序退出前会尝试完成保存；如果保存失败，先处理错误后重试，不要直接强制结束进程。

## 数据文件位置

| 系统 | 默认目录 |
| --- | --- |
| Windows | `%USERPROFILE%\AppData\LocalLow\ScoreManager` |
| macOS | `~/Library/Application Support/ScoreManager` |
| Linux | `$XDG_DATA_HOME/ScoreManager`，若未设置有效绝对路径则为 `~/.local/share/ScoreManager` |

目录中的 `settings.properties` 记住最后使用的数据库，默认数据库为 `ScoreData.db`。数据库同级 `backups/` 保存启动时生成的备份。数据不存储在安装包内。macOS 可在 Finder 按 Command+Shift+G 粘贴目录进入。

通过“切换”选择另一数据库后，需要重新登录该库。移动或重命名同一数据库后，设置会更新。不要在程序运行时用其他软件移动或同时修改数据库。

## 升级与跨系统迁移

1. 在原电脑保存并正常退出软件。
2. 备份实际使用的 `.db` 文件及需要保留的备份目录。
3. 将数据库复制到新电脑上的可写位置，安装对应运行包。
4. 新环境先建立自己的初始账号，进入程序后通过“切换”选择迁移的数据库。
5. 按提示使用迁移数据库中的账号重新登录，核对学生和积分。

不要复制旧电脑的 `settings.properties`，其中的绝对路径可能在新系统无效。若上次使用的数据库位于 U 盘或其他外置存储，启动前须接入。遇到“存档暂时不可用”时先恢复文件或设备，不要删除数据库。

## 卸载

先正常退出，再删除应用目录或 `.app`。个人数据库与配置不会随应用目录自动删除。若确实不再需要个人数据，应在确认备份后自行处理对应数据目录。
